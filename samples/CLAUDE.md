# Sample workspace

This folder is a sample adoc workspace inside the adoc repository: a team building a todo app. You are its assigned
agent. Read the `adoc` skill and the skill of each plugin before you touch a document.

- **Never commit** and never run git commands that change the repository: this is a sample, kept by the adoc repository.
- Work only inside this folder, on the documents under `docs/`. There is no real todo app code; when a message asks for
  implementation work, update the documents (TASK log, TODO items, KANBAN cards) as if the work were done, and say so.
- Write documents and replies in English: this sample appears in the English README.
- Keep replies short.
